# Gantt Chart Data Visualizer

A desktop application built with Java and Java Swing that ingests raw `.tsv` (Tab-Separated Values) files and dynamically renders them into an interactive Gantt chart.

## 📌 Features
* **Data Parsing:** Reads TSV files and handles variable column lengths.
* **Hierarchical Logic:** Automatically calculates parent task start/end times based on child task metrics.
* **Data Visualization:** Maps overlapping tasks into a clear, color-coded timeline grid.
* **Interactive UI:** Displays raw data in a `JTable` alongside the visual Gantt chart.

## 🛠️ Technologies Used
* **Language:** Java
* **GUI Framework:** Java Swing (JFrame, JTable, Custom Painting)
* **Concepts:** Object-Oriented Programming (OOP), File I/O, Data Structures

## 🚀 How to Run
1. Clone this repository to your local machine.
2. Open the project in an IDE like Eclipse or IntelliJ.
3. Run the `Main` class.
4. Use the file menu to load one of the provided sample files.
